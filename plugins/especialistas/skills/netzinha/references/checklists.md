# Netzinha — checklists de apoio

Carregue ao comparar muitas ferramentas, mapear uma modalidade inteira ou projetar
arquitetura de agentes.

**Aviso que vale para o arquivo inteiro:** aqui não há nome de "melhor modelo", preço
nem ranking — de propósito. Lista assim apodrece e passa a ensinar o erro. Aqui estão
os **eixos** de investigação; a resposta vem da pesquisa do momento.

## 1. O que vigiar no ecossistema

Novos modelos e versões · lançamentos · atualizações · APIs · preços · planos · limites
· benchmarks · documentação · mudança de política · nova funcionalidade · novos agentes
· plataformas · frameworks · aquisições · investimentos · mudança estratégica ·
ferramenta emergente · modelo open source · modelo proprietário · infraestrutura ·
chips · cloud.

Por modalidade: texto · imagem · vídeo · áudio e voz · código · documento ·
multimodal · robótica.

## 2. Empresas e organizações a acompanhar

OpenAI · Anthropic · Google DeepMind · Meta · xAI · Microsoft · NVIDIA · Amazon ·
Apple · Mistral · DeepSeek · Alibaba · Hugging Face · Stability AI · Runway ·
ElevenLabs · Perplexity · Cursor · Windsurf · GitHub · Replicate · Together AI · Groq.

**A lista não é fixa e não é completa.** Parte do seu trabalho é descobrir quem entrou e
quem saiu de relevância desde a última vez.

## 3. Líderes — e o peso certo da fala deles

Sam Altman · Demis Hassabis · Dario Amodei · Elon Musk · Jensen Huang · Mark Zuckerberg
· Satya Nadella · e outros relevantes.

Acompanhe anúncio, roadmap e estratégia — mas classifique sempre: **declaração ·
previsão · promessa · roadmap · lançamento · resultado · evidência.** Só os três últimos
sustentam recomendação.

## 4. Critérios de comparação entre modelos

Inteligência · raciocínio · precisão · janela de contexto · velocidade · latência ·
custo de entrada · custo de saída · multimodalidade · uso de ferramentas · function
calling · capacidade de agente · código · visão · áudio · vídeo · confiabilidade ·
taxa de alucinação · aderência a instrução · disponibilidade · limites de API ·
privacidade · hospedagem · possibilidade de uso local.

Sempre declare de qual tarefa a comparação depende.

## 5. IA para desenvolvimento

Coding agents · IDE com IA · geração de código · debugging · refatoração · testes ·
documentação · Git e GitHub · CI/CD · deploy · web · mobile · desktop · backend ·
frontend · APIs · banco de dados · cloud.

Compare desempenho real, não demonstração.

## 6. IA para imagem

Geração · edição · consistência de personagem · texto dentro da imagem · controle de
composição · estilo · resolução · edição por referência · uso comercial · ferramenta
local · modelo open source · custo.

Trabalho conjunto com `#zeimg` (produção) e `#chicodesign` (direção).

## 7. IA para vídeo

Geração · image-to-video · text-to-video · edição · avatar · lip sync · consistência ·
duração máxima · resolução · áudio · controle de câmera · custo · limitação · direito
de uso.

## 8. IA para áudio e voz

TTS · STT · clonagem de voz · dublagem · tradução · música · efeitos · separação de
faixas · transcrição.

Avalie: qualidade · naturalidade · idiomas suportados · custo · latência · direitos ·
limitação. Voz clonada exige consentimento — trate direito de voz como requisito, não
como detalhe.

## 9. IA local e open source

Modelo open source · open weights · execução local · Ollama · llama.cpp · vLLM · GPU ·
quantização · modelos menores · inferência local · privacidade · custo fixo contra
variável.

Local vence API quando: dado sensível · volume alto e constante · latência crítica ·
custo variável estourando · necessidade de funcionar offline.

## 10. Privacidade e segurança

Dado enviado · armazenamento · uso para treino · retenção · permissões · exposição de
informação · prompt injection · vazamento · dependência de terceiro · plano de saída se
o fornecedor mudar as regras.

## 11. Direitos e licenças

Licença do modelo · uso comercial · direito de imagem · direito de voz · copyright ·
termos da API · restrição comercial · propriedade do conteúdo gerado · política da
plataforma.

Regra específica ou recente: documentação oficial, sempre.

## 12. Arquitetura de agentes

Agente · subagente · ferramenta · memória · contexto · RAG · workflow · orquestração ·
MCP · function calling · multi-agent · pipeline · supervisão · avaliação · guardrails.

Ao projetar equipe, defina para cada membro: **escopo · gatilho de acionamento · dado
de entrada · formato de saída · quem valida · como se evita duplicação · qual o teto de
custo.**

Um agente só resolve? Então é um agente só.
