# Zizu — checklists de apoio

Carregue para investigar uma plataforma a fundo ou montar um plano de otimização
completo, ponta a ponta.

## 1. Modo "otimize isso" — os dez eixos

Custo · tokens · tempo · complexidade · quantidade de operações · ferramentas usadas ·
modelos usados · contexto carregado · retrabalho · qualidade final.

Analise os dez, depois apresente **uma** estratégia otimizada — não uma lista de
possibilidades.

## 2. Modo "economize" — ordem de busca

Recursos já disponíveis · recursos gratuitos · free tiers · open source · alternativas
baratas · combinação de ferramentas · automações · solução manual simples · solução paga
**só se necessária**.

## 3. Modo "custo zero" — o que declarar sempre

Tentar chegar a R$ 0 de verdade, mas deixar claro quando: custo zero exige mais
trabalho · existe limite · precisa de equipamento · depende de crédito · a solução
gratuita não escala · existe custo oculto.

Nunca chame de "gratuito" um teste limitado.

## 4. Radar de desperdício — categorias completas

Dinheiro · tokens · créditos · processamento · armazenamento · chamadas de API · tempo ·
contexto · memória · largura de banda · operação repetitiva · retrabalho.

## 5. Custo oculto — o que caçar

Limite de uso · renovação automática · cobrança por uso · armazenamento extra · custo de
API · custo de exportação · marca d'água · sistema de crédito · limite de velocidade ·
limite de projeto · limite de usuário · custo de escala.

## 6. Economia dentro de plataforma paga

Recurso nativo antes de ferramenta externa · aproveitar free tier · escolher modelo
adequado à tarefa · modelo pequeno pra tarefa simples · modelo caro só pra tarefa
complexa · reduzir resolução quando não necessária · evitar processamento duplicado ·
reutilizar resultado · armazenar resultado intermediário · agrupar operação quando isso
reduzir custo · evitar chamada redundante.

## 7. Economia de crédito (imagem, vídeo, processamento)

Testar primeiro · validar prompt antes da geração final · reduzir tentativas ·
reaproveitar resultado · gerar só o necessário · escolher resolução adequada · usar
ferramenta gratuita pra etapa preliminar.

## 8. Prompt econômico — o que cortar

Instrução redundante · contexto desnecessário · repetição · informação irrelevante ·
ambiguidade · prompt longo demais · tarefa que podia ser dividida · informação que
deveria estar em arquivo · informação que deveria ser persistente.

Meta: claro + preciso + eficiente + econômico — não só "menor".

## 9. Contexto inteligente

Resumir contexto · criar índice · criar arquivo de estado · criar documento de
referência · separar informação permanente da temporária · evitar repetição · recuperar
só o relevante.

## 10. Automação — onde procurar oportunidade

Renomeação · conversão · organização · classificação · extração · processamento ·
geração · publicação · sincronização · relatório · coleta de dados.

## 11. Macete de plataforma — o que mapear

Atalho · configuração · parâmetro · comando · menu pouco divulgado · recurso avançado ·
combinação de ferramentas · workflow · integração · automação · forma alternativa de
executar a mesma tarefa.

Fontes confiáveis: documentação oficial · fórum técnico · comunidade · changelog ·
tutorial · experiência relatada de usuário · repositório · teste independente.

## 12. Ambiente — mapa de otimização

| Ambiente | O que otimizar |
|---|---|
| Claude Code | contexto, comando, arquivo, agente, consumo |
| Codex | agente, ferramenta, contexto, execução |
| IDE | código, extensão, automação, workflow |
| Plataforma de IA | modelo, token, crédito, prompt |
| Ferramenta de design | recurso, exportação, template, funcionalidade |
| Ferramenta de imagem/vídeo | geração, crédito, resolução, workflow |
